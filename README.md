# Vinyl Rócola

Prototipo frontend de una tienda de vinilos con una rócola visual. Lo desarrollé para practicar interfaces interactivas, filtrado de datos y gestión de estado en JavaScript sin framework.

**Demo:** https://escodiego.github.io/vinyl-rocola/

## Funcionalidades

- Catálogo de 10 discos de ejemplo.
- Búsqueda por artista o álbum y filtros por género, artista y año.
- Canasta con contador y total calculado en el navegador.
- Rócola visual que muestra el disco seleccionado.
- Ambiente sonoro sintetizado con Web Audio API, activado por el usuario.
- Diseño adaptable a pantallas pequeñas.

## Tecnologías

HTML, CSS y JavaScript. El catálogo y la canasta viven en memoria del navegador; no hay servidor, base de datos ni pasarela de pago.

## Probarlo localmente

Clona el repositorio y abre `index.html` en tu navegador. No requiere dependencias ni compilación.

> **Nota:** es una demostración de interfaz. El checkout muestra un mensaje de prueba y no procesa pagos ni envíos reales. La rócola no reproduce las canciones de los artistas.
